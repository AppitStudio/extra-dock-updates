VERSION: 4.2.0
DETAILS:

✨ new: Fixed-mode docks can now be aligned to the left, center, or right of their edge (or top, center, or bottom for side edges). Find the new Alignment picker in Dock Settings.

✨ new: Folders with “always show name below icon” enabled can now use a separate custom label for the visible text under the icon, independent from the hover tooltip.

⚡ improved: Fullscreen detection was rewritten to work per-screen and react much faster, with fewer false positives and false negatives on Sequoia and Tahoe.

⚡ improved: Much better support for multiple identical monitors. ExtraDock now uses connection and port details to keep docks on the correct display after sleep, wake, and reconnects.

🐞 bug fix: Duplicating a dock now copies widgets and their configuration, appearance settings, theme effects, collapse icon customization, and layout options much more completely.

🐞 bug fix: Fixed a crash that could occur when enabling notification badges, especially on Tahoe.

🐞 bug fix: Fixed docks sometimes not showing up on the correct screen after waking from sleep or reconnecting a display.

🐞 bug fix: Fixed folder custom names not being saved and restored correctly between sessions.
