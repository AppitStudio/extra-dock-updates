VERSION: 4.3.4
DETAILS:

bug fix: No more 10–15 second freezes on multi-display Macs — resizing the Management window or changing dock settings re-queried every display's EDID identity through IOKit on each UI pass (hundreds of full registry enumerations per resize); display identity is now cached per display and refreshed only on connect/disconnect
bug fix: App-icon right-click window list is back — the open-window list had silently stopped appearing for nearly all users because it depended on a cache maintained only while App Previews (off by default) was enabled; the cache is now warmed on hover regardless of that setting, and the list also shows for single-window apps, matching the native Dock
bug fix: Dock clicks no longer beachball the app — clicking a dock icon synchronously asked the WindowServer for the full window list on the main thread; window snapshots now refresh in the background and clicks read an instant cached copy, with app-reopen resolution and notification-badge lookups also moved off the main thread and app icons cached instead of reloaded on every dock re-render
bug fix: Chrome web apps no longer relaunch after restoring a minimized window — restoring a minimized window of a Chrome-installed web app could trigger a second heavy "reopen", which for Chrome app shims means a full app-shim launch; a successfully restored minimized window now gets a light Dock-like activation and is never reopened twice, while genuinely off-Space windows keep the heavy reopen they need
